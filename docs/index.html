Keid

SSTP VPN client for macOS — for Keenetic (Netcraze), MikroTik, Windows Server and SoftEther

macOS has no SSTP. Keid adds it to the menu bar: enter the server once, then one click connects your MacBook to your router — and nothing leaves the Mac outside the tunnel.

Download for macOS Source on GitHub

Free · open source (MIT) · macOS 14+ · Apple Silicon & Intel · English & Russian

A VPN that does not leak

SSTP is plain HTTPS on port 443, so it gets through almost any network. Keid makes sure your traffic only ever goes that way.

Kill-switch on the firewall

From Connect until Disconnect, nothing leaves the Mac outside the tunnel: not while connecting, not after a drop, a wrong password or any other failure, and not from apps bound to Wi-Fi. Only the SSTP server and your local network stay reachable.

pf anchor · DNS only through the tunnel · IPv6 blocked

  • One click

    Connect and disconnect from the menu bar; the shield shows the state at a glance. Server, login and password are set in the app — no config files, no Terminal.

  • Full tunnel

    All IPv4 and DNS go through your home router, so its rules apply — including domain-based routing on Keenetic.

  • Back on its own

    Reconnects after a Wi-Fi change, sleep or a server restart, at once when the network returns. Stops at once on a wrong password, so the account is not locked.

  • Made for the Mac

    Universal app for Apple Silicon and Intel, notifications, data counters, launch at login, English and Russian.

Lives in the menu bar

One panel to connect and see the tunnel, one window to set the server up.

Works with

Any SSTP server with MS-CHAPv2 should work; these are the common ones.

  • Keenetic / NetcrazeSSTP VPN server, KeenDNS
  • MikroTikRouterOS SSTP server
  • Windows ServerRRAS with SSTP
  • SoftEther VPNSSTP enabled

Install

No Homebrew, no Docker, no Terminal.

  1. Download

    Get the DMG from Releases and drag Keid into Applications.

  2. Allow

    The app is not notarized: on first launch open System Settings → Privacy & Security → Open Anyway.

  3. Set up

    Click the shield → Settings, enter the server, login and password, then Save and Install.

  4. Connect

    One click. Connecting later needs no password.
